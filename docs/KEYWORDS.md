## Add metadata on GitHub

1. Open [the Folio repository](https://github.com/ThinkHomeo/folio-ocr-studio).
2. Select the gear beside **About**.
3. Paste the description and website above.
4. Add the selected topics and save changes.

README headings, introductory text, screenshots and usage examples also use
these terms naturally. Keywords describe the project; they do not guarantee
search ranking. Public indexable links can help people discover ThinkHomeo.in;
localhost links do not create a publicly indexed backlink.
