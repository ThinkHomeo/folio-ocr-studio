Python & app packages

Python 3.10 or newer, 64-bit. A separate .venv folder keeps this app's packages together.

Download Python
Manual installation & troubleshooting

Open PowerShell in the app folder and run these commands. If you copied a .venv from another computer, rename it first and create a fresh environment.

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .

Select Add Python to PATH in the Python installer. For a missing Windows DLL, install Microsoft's Visual C++ Redistributable, then recheck.

Microsoft Visual C++ download instructions
2

OCR engine & languages

Tesseract reads the text. English and Hindi use their own language data files.

Tesseract installer

Tesseract installation uses Windows Package Manager (winget) and may request administrator permission. Language packs download from the Tesseract project's tessdata_fast repository into this app's tessdata folder.

Manual Tesseract setup

If winget is unavailable, use the installer link above. Install to C:\Program Files\Tesseract-OCR, or add another installation location to PATH. Select English and Hindi language data if offered, then recheck.

winget install --id UB-Mannheim.TesseractOCR --exact --source winget

For an existing installation elsewhere, set TESSERACT_CMD to its tesseract.exe path before opening the launcher. To download language packs manually, copy both eng.traineddata and hin.traineddata from tessdata_fast into this app's tessdata folder.

3

Format-aware models Optional

Text OCR works without these files. The TPB 1891 profile uses them to help classify printed styles.

Copy mlp_model.pkl and shape_model.pkl from your trusted existing installation into this app's out folder. These custom models have no public download link. File presence is checked here; compatibility and recognition quality require OCR validation.

Moving to another computer
Copy this app folder, including out and tessdata, then run setup_folio.bat on the new Windows computer. Create a fresh .venv there. Install Python first if the launcher requests it.
To keep previous documents and corrections, stop the old server before copying the entire dev-data or app-data folder, including scans and the database. The launcher selects dev-data when present; otherwise it uses app-data. Use run_app.bat --data-dir "your-folder" for another location.
